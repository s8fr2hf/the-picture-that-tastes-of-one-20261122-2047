One picture of food, drawn entirely in code: a single ripe strawberry, filling
the frame — glossy skin, pale seeds in dimples, a fresh green calyx and stem,
water droplets, soft light from the upper left, on a warm cream background.
No photo, no network, no external assets: `main.ts` renders the berry pixel by
pixel and writes its own PNG with the Node standard library only.

## Run

```sh
node main.ts            # writes /output/entry.png
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```

Output: a 1024×1024 PNG, well under the 1 MiB limit.
