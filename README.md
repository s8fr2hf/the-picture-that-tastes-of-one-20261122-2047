# The picture that tastes of one ingredient

One ripe strawberry, drawn entirely in code. No photos, no network, no
external images: `main.ts` renders the berry per pixel — glossy red skin
with specular highlights, pale golden seeds sitting in dimples, a fresh
green calyx with veins and a stem, water droplets, on a warm cream
background with a soft ground shadow — and writes it to `entry.png`
with a hand-rolled PNG encoder (Node stdlib only).

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.png (1024x1024, under 1 MiB)
```

Requires Node 22. No dependencies to install.
